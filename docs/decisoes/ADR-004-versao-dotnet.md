# ADR-004 — Versão do .NET

## Status

Aceito

## Contexto

O CasaHub será desenvolvido como um produto de longo prazo, portanto a versão do framework deve priorizar estabilidade, suporte prolongado e evolução tecnológica.

## Decisão

A aplicação utilizará .NET 10 LTS.

## Consequências

### Positivas

- Maior período de suporte.
- Uso de uma versão atual da plataforma.
- Acesso às melhorias recentes do ecossistema.

### Negativas

- Algumas empresas podem ainda utilizar versões anteriores.
- Pode haver menor quantidade de exemplos comparado ao .NET 8.
