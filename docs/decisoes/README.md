# Architecture Decision Records (ADR)

Esta pasta contém os registros das principais decisões arquiteturais do CasaHub.

Os ADRs documentam o contexto, a decisão tomada e suas consequências, servindo como histórico técnico do projeto.

## ADRs

| ADR | Descrição |
|------|-----------|
| ADR-001 | Arquitetura da aplicação |
| ADR-002 | Organização por funcionalidades |
| ADR-003 | Banco de dados PostgreSQL |

Novas decisões arquiteturais deverão ser registradas sempre que impactarem significativamente a estrutura ou a evolução do sistema.
